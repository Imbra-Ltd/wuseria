### Conclusion

Voigtlander deliberately withholds MTF charts from all Nokton lenses (verified across catalog and website). APO-LANTHAR lenses from the same manufacturer get MTF charts (SVG on website + catalog). This is a consistent corporate policy. Third-party measured MTF is the only path.

## Character lens classification

This lens is a **Tier 1 purpose-built character lens** (Double Gauss derivative, f/1.2, 12-blade aperture). The X-mount version uses 6 groups / 10 elements with 1 aspherical and 2 ED elements — a different design from the VM mount version.
