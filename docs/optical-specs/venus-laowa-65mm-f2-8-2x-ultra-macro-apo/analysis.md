## Chart legend

- Y-axis: MTF contrast (0–1)
- X-axis: image height (mm)
- Curves: 10S, 10T, 30S, 30T (10 lp/mm and 30 lp/mm sagittal + tangential)
- Aperture: wide-open (f/2.8) at each focus distance
- Macro lens: MTF varies with focus distance / magnification, so the
  vendor publishes three panels (1:1, 2:1, infinity) instead of one
