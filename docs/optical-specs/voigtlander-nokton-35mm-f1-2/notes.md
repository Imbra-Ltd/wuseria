## Character lens classification

**Tier 1 purpose-built character lens.** Traditional "8-element" style — all spherical lenses, 6 groups / 8 elements. The catalog describes it as delivering "smooth and large bokeh" (なめらかで大きなボケ味). No aspherical elements = classic rendering with intentional aberrations wide open.
