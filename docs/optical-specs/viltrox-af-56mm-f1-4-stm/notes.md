# Viltrox AF 56mm f/1.4 STM — Notes

## Special element counts

The sansmirror review confirms 10 elements in 9 groups with ED and HR
glass, but does not provide exact counts for each type. The counts
recorded (1 ED, 1 HR) are inferred from the Viltrox AF 33mm f/1.4 STM,
which shares the same 10E/9G optical formula and generation and has
confirmed counts from OpticalLimits.

If an independent source with exact counts for the 56mm f/1.4 is found,
update both lenses.ts and analysis.md.
