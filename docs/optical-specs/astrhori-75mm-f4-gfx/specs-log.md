## Caveats

- **Element count discrepancy:** Official page says 11/8, pre-release leak (FujiRumors Aug 2022) says 8/6. cinegear.nl has both values in different sections. Using 11/8 per official page as authoritative.
- Official text says "ED lenses" (no count) and "two high-refractive glass" — unlike 40mm/55mm which specify "2 ED", the 75mm omits the ED count
- Cannot populate edElements without a confirmed count
- No MTF charts or construction diagrams published anywhere
