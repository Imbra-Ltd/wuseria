## Notes

NiSi protects the proprietary engineering of their optical glass blocks.
Element/group counts have never been disclosed — not on the official NiSi
Global Store, regional portals (NiSi UK), or industry analysis (Newsshooter,
CineD). Any element/group configuration found online is unverified speculation.

Instead of element-to-group architecture, NiSi establishes accuracy through
standardized physical and optical configurations:

**Verified optical configuration:**

- Image circle: 46mm (full-frame and large-format sensor coverage)
- Focus breathing: concealed internal rear-focus element layout
- Aperture: 10-blade iris, completely rounded bokeh across the set
- Glass types: ED (Extra-Low Dispersion) + HR (High Refractive) elements

**Verified mechanical specs (PL mount):**

- Weight: ~800g uniform across core set (14-85mm); 135mm slightly heavier
- Gear: 0.8 MOD focus and iris rings, matched position across all lenses
- Front: 80mm outer diameter, 77mm filter thread (except 14mm bulbous front)
