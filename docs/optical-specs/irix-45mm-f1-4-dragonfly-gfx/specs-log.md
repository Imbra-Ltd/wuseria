## Caveats

- GFX and DSLR versions share identical optical construction (11/9) per FujiRumors review. Physical dimensions differ due to mount/flange distance (GFX: 1120g, DSLR: 905g).
- Max magnification: LensTip GFX spec says 0.15x; Phillip Reeve measured ~0.18x for DSLR version. Database currently has 0.1 — LensTip spec sheet value (0.15) is more authoritative.
