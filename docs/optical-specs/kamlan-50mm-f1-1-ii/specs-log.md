# Kamlan 50mm f/1.1 II — Specs Log

## Version resolution

The DB previously stored Mark I specs (248g, 52mm filter, 5/5 optics) but the
officialUrl pointed to the Mark II page. The Mark I is discontinued — no page
exists on the Kamlan site. DB updated to Mark II (model renamed to "50mm f/1.1 II").
