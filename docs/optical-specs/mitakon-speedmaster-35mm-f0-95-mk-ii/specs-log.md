## Optical construction

- **Elements / Groups:** 11 / 8 (zyoptics.net spec table, confirmed by AllPhotoLenses)
- **Special elements:** 1 ED + 2 Extra-High Refractive Index + 1 High Refractive Index = 1 ED, 3 HRI total
- **Coating:** not published (no branded coating name; Alik Griffin notes good coating quality)
- **Construction diagram:** not found
- **MTF chart:** not found

## Caveats

- B&H simplifies to "One Extra-Low Dispersion Element" and does not list HRI separately in key features
- zyoptics.net page distinguishes "Extra-High Refractive Index" (2) from "High Refractive Index" (1) — both are HRI glass types with different refractive indices, summed as 3 HRI
